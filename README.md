# Eirik
This software package provides a user-friendly graphical user interface (GUI) for handling *.dat files produced by HEKA PatchMaster during in vitro electrophysiology recordings.

For running the program, type 'Eirik' in the command window of MatLab IDE and the main GUI menu will appear on the screen. 
The user can then upload the first HEKA '*.dat' file and start working with it.
